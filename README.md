# Music Editor Bot

Telegram-бот: редактирует аудио (название, исполнитель, описание, обложка, эффекты, формат),
конвертирует видео, делает кружки. Языки: **O'zbekcha, Русский, English** (три кнопки выбора языка при /start, смена — /lang).
Есть админ-панель (на русском).

## Установка

1. Python 3.10+
2. `pip install -r requirements.txt` — вместе с этим ставится встроенный ffmpeg (imageio-ffmpeg);
   если ffmpeg уже есть в системе, используется он.
3. В `.env`: `BOT_TOKEN`, `ADMIN_ID`, по желанию `CHANNEL_ID`.
4. `python bot.py` — в логе должна быть строка `ffmpeg: ...`.

## Аудио (пришли аудио-файл до 20 МБ)

- Название, исполнитель, описание, обложка. Везде есть кнопка «⬅️ Назад».
- Формат результата: MP3, M4A, MP4 (видео: обложка + звук), OGG, FLAC, WAV, голосовое сообщение
  и **кружок** (круглое видео до 60 секунд; если добавлена обложка — она вращается).
- Формат имени файла: `Исполнитель - Название`, `Название`, `Название (эффект)`.
- 14 эффектов: 8D, концертный зал, большой зал, бас-буст, slowed+reverb, nightcore,
  lo-fi, под водой, телефон, пещера, широкое стерео, хорус, **flanger**, **bit crush** (словарь `EFFECTS` в effects.py).
- После готового трека кнопка «🔁 Изменить ещё раз» возвращает в редактор с теми же настройками
  (исходный файл хранится в temp-папке около часа или до следующего присланного файла).

## Видео (пришли видео до 20 МБ)

MP4, MKV, WEBM, AVI, MOV, GIF, **кружок** (квадрат до 60 сек) или «Музыка из видео» (MP3 → редактор).
Кнопка «🔁 Конвертировать ещё раз» работает так же.

## Копии в канал (необязательно)

Если указать `CHANNEL_ID`, бот копирует в канал **готовые треки и картинки-обложки**, которые прислали
пользователи (с именем, @username и id автора). Пользователям об этом сообщается в приветствии.

1. Создай канал и добавь бота администратором с правом публиковать сообщения.
2. Узнай ID канала (например, перешли пост из канала боту @getidsbot) или возьми `@username`.
3. В `.env`: `CHANNEL_ID=-1001234567890`. Пустое значение — копирование выключено.

## Админ-панель — /admin (только ADMIN_ID)

Статистика, список пользователей (с языком), рассылка всем (с предпросмотром), личное сообщение по ID.

**📌 Обязательная подписка**: «Добавить канал» (@username или ID; бот должен быть администратором канала).
Пока пользователь не подписан на все каналы из списка, бот показывает только экран подписки; после нажатия
«Я подписался» (бот проверяет подписку) всё работает как обычно. Если проверка технически невозможна (бот не админ),
пользователь не блокируется. Админ не проверяется.

**📢 Рассылка**: на экране подтверждения можно «➕ Добавить кнопку к рассылке» (текст + ссылка) и/или отправить
вместе с общими кнопками-ссылками.

**🔗 Кнопки-ссылки**: «Добавить» → текст кнопки → ссылка (`https://…`, `t.me/…` или `@username`). Кнопки показываются
под приветствием (рядом с кнопками языка) и под сообщением «Готово»; при рассылке можно выбрать
«Отправить с кнопками». Удаление — нажатием на 🗑. Максимум 8.

## Безопасность

Токен был отправлен в открытом чате — перевыпусти: @BotFather → /revoke, затем впиши новый в `.env`.
Временные файлы хранятся в системной temp-папке, не в папке проекта.
